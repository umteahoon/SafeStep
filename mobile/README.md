# SafeStep Mobile (React Native / Expo)

`frontend/`(웹, Capacitor 안드로이드 앱)와는 별개의 **네이티브 모바일 앱**입니다. `backend/`, `supabase/`와 **같은 Supabase 프로젝트·같은 백엔드 API**를 그대로 공유하므로, 웹에서 만든 계정으로 이 앱에도 바로 로그인할 수 있고 DB/RLS/Realtime도 동일하게 적용됩니다.

> 📌 **이 문서는 모바일 앱의 변경 사항을 계속 기록하는 문서입니다.** 모바일 코드를 고치거나 기능을 추가할 때마다 아래 [구현 현황](#구현-현황)과 [변경 이력](#변경-이력)을 함께 갱신하세요. (루트 `README.md`는 웹 기준 문서이며 모바일 내용은 여기에만 적습니다.)

## 방침
- **기능**은 루트 `README.md`에 있는 웹 버전과 동일하게 맞춥니다.
- **UI/UX**는 웹 레이아웃을 옮기지 않고 모바일에 맞게 새로 설계합니다 (하단 탭 + 스택 내비게이션, 표 → 카드 목록, 모달 → 바텀시트/페이지시트, `<input type=date/month>` → 스텝퍼, 호버 동작 → 길게 누르기 등).
- 웹 코드를 공유하지 않습니다. 대신 아래 두 가지는 웹과 반드시 맞춰야 합니다.
  - **Supabase 프로젝트**: `.env`에 `frontend/.env` / `backend/.env`와 **동일한 Supabase URL/anon key**를 넣으세요. 웹에서 실행한 모든 `supabase/migration_*.sql`이 적용된 상태여야 합니다.
  - **타입**: `src/types/index.ts`는 `frontend/src/types/index.ts`의 복사본입니다. DB 컬럼을 바꾸면 양쪽 다 수정하세요.

## 실행하기

```bash
cd mobile
npm install
cp .env.example .env   # 값 채우기
npm start              # Expo 개발 서버 — QR코드를 Expo Go 앱으로 스캔하면 실기기에서 확인
```

- `npm run android` / `npm run ios` — 에뮬레이터/시뮬레이터 (Android Studio / Xcode 필요)
- `npm run typecheck` — TypeScript 검사
- 환경변수는 `EXPO_PUBLIC_` 접두사가 붙어야 번들에 포함됩니다.

| 변수 | 설명 |
|---|---|
| `EXPO_PUBLIC_SUPABASE_URL` / `EXPO_PUBLIC_SUPABASE_ANON_KEY` | 웹과 같은 Supabase 프로젝트 |
| `EXPO_PUBLIC_API_BASE_URL` | `backend/` API 주소 (끝에 `/api` 금지 — 코드가 경로 앞에 `/api`를 붙입니다) |
| `EXPO_PUBLIC_NAVER_MAP_CLIENT_ID` | 네이버 지도 클라이언트 ID. 비우면 지도 없이 지점 목록만 표시 |
| `EXPO_PUBLIC_NAVER_MAP_WEB_URL` | 네이버 클라우드 콘솔 "Web 서비스 URL"에 등록한 주소와 동일하게 (기본 `http://localhost`) |
| `EXPO_PUBLIC_TOSS_CLIENT_KEY` | 토스페이먼츠 결제위젯 클라이언트 키 (`test_ck_...`) |

> 카메라(QR 스캔)·사진 선택·위치 권한은 `app.json`의 플러그인에 등록되어 있습니다. **Expo Go에서도 동작하지만**, 네이티브 설정을 바꾼 뒤에는 `npx expo prebuild` / 개발 빌드가 필요할 수 있습니다.

## 내비게이션 구조

하단 탭은 로그인 상태/역할에 따라 구성이 달라집니다. **로그인 전(일반 이용자)**: 홈 · 카페 찾기 · 내 정보. **원장·강사**: 홈 · 지도 · 채팅 · 팀 · 내 정보. **학생**: 홈 · 지도 · 내 공부 · 채팅 · 내 정보 (팀은 홈·내 정보에서 진입). **학부모**: 홈 · 지도 · 채팅 · 내 정보. **슈퍼관리자**: 홈 · 지도 · 내 정보. 키오스크는 탭이 아니라 홈의 바로가기로 진입합니다.

웹의 `homeForRole` 역할별 홈은 **내 정보 탭의 역할별 메뉴**로 대체했습니다.

| 역할 | 내 정보 메뉴 |
|---|---|
| 슈퍼 관리자 | 플랫폼 관리, 접속 로그 |
| 원장 | 대시보드, 학생/강사/반·시간표/출석부, 이용권 결제, 신고 관제 (학원 미연결이면 학원 등록) |
| 강사(승인) | 출석부, 학생 관리, 반·시간표, 신고 관제 |
| 학생 | 내 출결 QR, 이용권 |
| 학부모 | 자녀 출결 리포트 |

## 웹과의 UI 차이 (의도된 것)
- 표(테이블) → 카드 목록, 가로 스크롤 최소화
- 채팅 참여자/출석 패널 → 페이지시트 모달, 팀의 좌측 사이드바 → 상단 채널 칩 + "팀 정보" 시트
- 호버로 보이던 수정/삭제 → 메시지 길게 누르기
- 오프라인 감지: `navigator.onLine` → `@react-native-community/netinfo`
- 파일 선택: `<input type=file>` → `expo-image-picker`, 클립보드: `expo-clipboard`, 엑셀 저장: 공유 시트
- `window.confirm` → `Alert` (`lib/confirm.ts`)

## 변경 이력

### 2026-10-07 — 원장·강사·학부모에게 지도·커뮤니티 숨김
- **대상**: 학원 원장(ACADEMY_ADMIN)·강사(TEACHER)·학부모(PARENT). 운영/자녀 관리가 목적이라 이용자용 스터디카페 탐색·커뮤니티를 노출하지 않음. 비로그인·일반 회원·학생·슈퍼관리자는 기존대로 이용 가능 (규칙은 `lib/teams.ts`의 `EXPLORE_BLOCKED` / `canExplore()` 한 곳)
- **숨기는 곳**: 하단 **지도·커뮤니티 탭**(원장·강사·학부모 탭은 홈 · 채팅 · 내 정보), 학부모 홈의 "스터디카페" 바로가기, 내 정보의 **즐겨찾기·내 글 활동 요약**
- **직접 열어도 차단**(보조 안전장치, `BlockRoles`): 지도·좌석 도면·커뮤니티 탭·스터디카페 게시판·글 상세는 "이용할 수 없는 화면이에요", 글쓰기는 "접근 권한이 없습니다". 진입점은 이미 숨겨져 있음
- 원장·강사 홈에는 원래 스터디카페 목록·이야기 섹션이 없었음(학생·비로그인 전용)
- 검증: 테스트 157개 통과 — 신규: 3개 역할 × (5개 화면 직접 열기 차단 + 글쓰기 차단 + 홈·내 정보에 관련 항목 없음) + 허용 역할 4종 유지 + 역할별 탭 구성(원장·강사·학부모 = 홈·채팅·내 정보). 테스트 도구의 대기 방식도 보강(학생 역할 타이밍)

### 2026-10-07 — 로그인·회원가입·내 정보 UI 재설계
